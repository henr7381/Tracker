========== Sensor Model ==========

--- SensorModel.h ---

Result = std::variant<Ray, int>

class SensorModel
Constructor:
	SensorModel(Vector3D, Point3D)
		Vector3D - The direction the camera is pointing
		Point3D  - The center of the sensor glass
Members:
	Xres     - FP pixel width
	Yres     - FP pixel height
	Horz_fov - FP FOV width
	Vert_fov - FP FOV height
	principal_X  - The pixel distance from the center of the FP to the X 
		       edge of the FP
	principal_Y  - The pixel distance from the center of the FP to the Y
		       edge of the FP
	focal_length     - The distance from the focal plane to the sensor glass
	CameraLocation_W - The world location of the sensor glass
	CameraFrameX_W   - The world vector describing the x axis of the 
			   sensor's coordinate frame
	CameraFrameY_W   - The world vector describing the y axis of the
			   sensor's coordinate frame
	CameraFrameZ_W   - The world vector describing the z axis of the 
			   sensor's coordinate frame
	DetectedVector_L - The object specific sensor frame vector
			   describing a vector to the latest
			   detected pixel on the object's FP
	DetectedRay_W    - A world ray describing the latest sensor-to-pixel
			   detection
Functions:
	void MainLoop()
	Result detectedPixel(x, y)
		Param [in]  x	FP pixel x location
		Param [in]  y	FP pixel y location
		Param [out] 	The result, either a Ray or error code
	void ProceccImage()
